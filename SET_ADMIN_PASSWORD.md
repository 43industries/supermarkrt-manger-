# 🔐 Set Admin Password

To change the admin password, run:

```bash
node change-password.js admin YOUR_NEW_PASSWORD
```

**Example:**
```bash
node change-password.js admin MySecurePassword123
```

Replace `YOUR_NEW_PASSWORD` with your desired password.

---

## Current Default
- Username: `admin`
- Password: `admin123`

---

After running the command, login with:
- Username: `admin`
- Password: `YOUR_NEW_PASSWORD`
