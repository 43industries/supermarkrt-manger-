## 🚂 Step 2: Deploy to Railway (3 minutes)

### 1. Go to Railway
👉 **Click here:** https://railway.app

### 2. Sign Up/Login
- Click **"Start a New Project"**
- Click **"Login with GitHub"** (easiest way)
- Authorize Railway to access your GitHub

### 3. Deploy Your Repository
- Click **"New Project"** button
- Select **"Deploy from GitHub repo"**
- Find your repository: `supermarkrt-manger-` (or `43industries/supermarkrt-manger-`)
- Click on it

### 4. Wait for Deployment
Railway will automatically:
- ✅ Detect Node.js
- ✅ Run `npm install`
- ✅ Run `npm start`
- ⏱️ Takes 1-2 minutes

### 5. Get Your Live URL!
Railway will give you a URL like:
- `https://supermarkrt-manger-production.up.railway.app`
- Or similar

**Click the URL to open your live POS system!** 🎉

## ⚙️ Environment Variables (Optional - For M-Pesa)

If you're using M-Pesa integration:

1. In Railway dashboard:
   - Go to your project → **Variables** tab
   - Click **"New Variable"**
   - Add:
     - `MPESA_CONSUMER_KEY=your_key`
     - `MPESA_CONSUMER_SECRET=your_secret`
     - `MPESA_SHORTCODE=your_shortcode`
     - `MPESA_PASSKEY=your_passkey`
     - `MPESA_ENVIRONMENT=sandbox`

2. Redeploy:
   - Go to **Deployments** tab
   - Click **"..."** on latest deployment
   - Click **"Redeploy"**

## 🆘 Troubleshooting

**App not starting?**
- Check Railway logs: Dashboard → Deployments → Logs
- Make sure deployment status is "Active"

**Can't access site?**
- Check deployment is complete (green checkmark)
- Try incognito/private browser window
- Wait a minute after deployment completes

**Database errors?**
- Railway supports SQLite ✅
- Database is created automatically ✅
- Check logs for specific errors
